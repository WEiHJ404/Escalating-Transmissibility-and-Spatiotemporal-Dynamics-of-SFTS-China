# Repository for SFTS Dynamic Modeling Study

This repository provides the scripts, figures, and source data files for the manuscript:

**Escalating Transmissibility of SFTS in High-Endemic China**

## Contents

- `script/` - code for data analysis and modeling
- `Figures/` - figures included in the manuscript
- `Source Data files/` - source data supporting the findings of this study

## Study overview

Severe fever with thrombocytopenia syndrome (SFTS) is an emerging tick-borne infectious disease of growing public health concern. This study quantifies transmissibility and characterizes the spatiotemporal dynamics of SFTS in Anhui Province, China, from 2019 to 2023.
